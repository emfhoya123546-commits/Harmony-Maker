조옮김

1멜로디 가져오기

설정

트랙이 여러 개면 가장 위에서 혼자 노래하는 트랙을 멜로디로 고르고, 나머지 트랙으로 코드를 찾아요. 멜로디만 있으면 멜로디로 코드를 추측해요.

Sibelius, MuseScore, Finale에서 MusicXML로 내보낸 파일이에요. 멜로디, 박자, 키, 템포, 코드 기호까지 읽어요.

사진 인식 안내
  1. Claude가 사진을 보고 멜로디와 코드 기호를 읽어요. 30초~2분쯤 걸리고, 쓸 때마다 Claude 사용량이 들어요.
  2. 보컬 멜로디가 한 줄로 있는 리드시트가 가장 잘 돼요. 여러 페이지면 순서대로 한 번에 같이 올려요.
  3. 반복 기호는 펼치지 않고 적힌 그대로 읽어요.
  4. 사진 인식은 틀린 음이 생길 수 있어요. 파일이 있으면 MusicXML이 훨씬 정확해요.

악보 사진·캡처를 바로 읽는 기능은 claude.ai에서 열었을 때만 돼요. 여기서는 아래 방법으로 MusicXML로 바꾼 다음 위에 올려 주세요.

사진·PDF 악보를 MusicXML로 바꾸는 법

Audiveris (무료 · Windows, Mac, Linux)

  1. Audiveris 다운로드 페이지에서 내 컴퓨터에 맞는 설치 파일을 받아 설치해요.
  2. Audiveris에서 악보 사진이나 PDF를 열어요. 스캔처럼 똑바로 찍은 선명한 이미지일수록 잘 읽어요.
  3. 인식(Transcribe)을 실행하고, 틀린 음이 보이면 화면에서 고쳐요.
  4. MusicXML(.mxl)로 내보내기(Export)한 다음, 이 탭의 "악보 파일 올리기"에 올려요.

설치 없이 하고 싶으면

  1. MuseScore 웹사이트의 PDF 가져오기로 PDF를 올리면 MusicXML로 받을 수 있어요. 인식 엔진이 오래된 버전이라 정확도는 Audiveris보다 떨어질 수 있어요.

어떤 방법이든 인식이 완벽하지 않아요. 불러온 다음 피아노롤에서 한 번 훑어보고 고쳐 주세요.

녹음하는 법 · 가이드 트랙
  1. 아래 ②에 코드를 마디마다 적고 BPM을 맞춰요.
  2. 가이드 트랙을 저장하거나, 위의 ▶ 재생을 카운트인 켜고 틀어요.
  3. 헤드폰으로 들으면서 멜로디만 녹음해요. 스피커 소리가 섞이면 인식이 틀어져요.
  4. 녹음 파일을 위에 올려요.
인식 설정

녹음 시작점

  1. 오른쪽 피아노롤 빈 곳을 누르면 음이 생겨요. 누른 채로 끌면 길이가 정해져요.
  2. 음을 끌면 위아래로 음 높이, 좌우로 위치가 바뀌어요.
  3. 음 오른쪽 끝을 끌면 길이가 바뀌어요.
  4. 더블클릭하거나 선택하고 Del을 누르면 지워져요.
  5. 칸 크기는 롤 위의 스냅에서 골라요.

2코드

오른쪽 코드표에 마디마다 직접 적거나, 반주 MIDI를 올려서 자동으로 찾은 뒤 고쳐 써요.

3화음 고르기

구간별 스타일

구간에 넣은 마디는 그 구간에서 고른 화음만 써요. 구간 밖의 마디는 위에서 고른 화음을 써요. 구간이 겹치면 아래쪽 구간이 이겨요.

아직 구간이 없어요. 모든 마디가 위에서 고른 화음을 따라요.

성부끼리 교차하지 않고, 평행 5도·8도를 피하고, 3음이 빠지지 않게, 앞 음에서 가장 적게 움직이도록 배치해요. 음역 밖 음은 피아노롤에 빨간 점선으로 표시돼요.

피아노롤 맨 위 줄을 누르거나 끌면 마디별로 화음을 켜고 꺼요.

4내보내기

.zip 안에 .mid 파일이 들어 있어요. 압축을 풀고 Cubase로 드래그하면 트랙별로 들어가요.

MuseScore, Sibelius, Finale에서 열면 파트별 악보가 돼요. 코드 기호도 같이 들어가요.

코드표

세로줄 |로 마디를 나눠요. 마디 안에 코드가 2개면 반마디씩, 4개면 한 박씩 들어가요. /는 앞 코드 유지, %는 앞 마디 반복이에요. 세로줄이 없으면 코드 하나가 한 마디예요.
